# 3D框点云可视化和交互调整工具

这是一个用于在点云上绘制和调整3D边界框的交互式工具。

## 🎨 版本说明

本工具提供两个版本：
- **GUI版本 (visualize_box_gui.py)** - 图形界面，使用滑动条直观调整参数 ⭐**推荐**
- **键盘版本 (visualize_box.py)** - 使用键盘快捷键控制

## 功能特点

- ✅ 加载和可视化点云文件（PCD格式）
- ✅ 绘制3D边界框
- ✅ 3D框的底边自动与地面点云共面
- ✅ 图形界面实时调整框的位置、朝向和大小
- ✅ 滑动条控制所有参数
- ✅ 保存3D框参数到JSON文件

## 安装依赖

```bash
pip install -r requirements.txt
```

或者直接安装：

```bash
pip install open3d numpy
```

## 使用方法

### 方式一：GUI版本（⭐推荐）

```bash
# 使用图形界面，直观调整参数
python visualize_box_gui.py box1.pcd ground.pcd
```

### 方式二：使用批处理脚本（Windows）

```bash
# 双击运行或在命令行执行
run_box_visualizer.bat
```

### 方式三：键盘控制版本

```bash
# 使用键盘快捷键控制
python visualize_box.py box1.pcd ground.pcd
```

## 操作说明

### GUI版本操作

GUI版本提供直观的图形界面，右侧面板包含所有控制选项：

**位置调整**
- X位置滑动条：左右移动3D框
- Y位置滑动条：前后移动3D框

**旋转调整**
- 旋转滑动条：调整3D框绕Z轴的旋转角度（-180° 到 180°）

**大小调整**
- 长度(X)滑动条：调整3D框的长度
- 宽度(Y)滑动条：调整3D框的宽度
- 高度(Z)滑动条：调整3D框的高度

**按钮操作**
- **重置按钮**：恢复到初始状态
- **保存参数按钮**：保存当前3D框参数到JSON文件

---

### 键盘版本操作

### 移动3D框
- **↑/↓ 方向键**: 前后移动
- **←/→ 方向键**: 左右移动

### 旋转3D框
- **Q**: 逆时针旋转（绕Z轴）
- **E**: 顺时针旋转（绕Z轴）

### 调整3D框大小
- **I**: 增加长度（X轴）
- **K**: 减少长度（X轴）
- **L**: 增加宽度（Y轴）
- **J**: 减少宽度（Y轴）
- **U**: 增加高度（Z轴）
- **O**: 减少高度（Z轴）

### 其他操作
- **P**: 保存当前3D框参数到 `box_parameters.json`
- **ESC**: 退出程序

## 输出格式

当按下 **P** 键时，程序会将3D框参数保存到 `box_parameters.json` 文件中，格式如下：

```json
{
    "center": [x, y, z],
    "size": [length, width, height],
    "rotation": 角度（弧度）,
    "rotation_degrees": 角度（度）
}
```

## 技术细节

### 地面平面拟合
程序使用RANSAC算法自动拟合地面点云的平面方程，确保3D框的底边始终与地面共面。

### 颜色方案
- **橙色**: Box点云
- **灰色**: Ground点云
- **红色**: 3D边界框

## 注意事项

1. 确保PCD文件格式正确
2. 地面点云应该包含足够的点（至少3个点）以进行平面拟合
3. 所有的位置调整都会自动保持底边与地面共面
4. 3D框的最小尺寸被限制为0.1单位，防止框消失
